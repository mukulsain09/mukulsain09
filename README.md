## 🚀 Featured Projects

### 🔎 Digital Forensics & Incident Response (DFIR)

* **[ProvGraph-DFIR](https://github.com/mukulsain09/ProvGraph-DFIR)**  
  *Deterministic Causal Slicing & Lossless Hierarchical Contraction Engine for Windows Telemetry*  
  Reconstructs evidence-linked, cycle-free causal execution Directed Acyclic Graphs (DAGs) from high-volume Windows Sysmon and EVTX event streams. Implements monotonic total-order event timestamping, bidirectional recursive CTE slicing, and lossless structural contraction with reversible drill-down expansion (`Expand()`).  
  `Python` • `NetworkX` • `SQLite CTE` • `Cytoscape.js` • `Streamlit`

* **[Windows Forensic Analysis Suite v2.0](https://github.com/mukulsain09/Windows-Forensic-Analysis-Suite-Version-2.0-)**  
  *Automated Windows Evidence Extraction & Visual Correlation Suite*  
  Automates the collection, parsing, and multi-timeline correlation of 8+ critical Windows forensic artifacts (Prefetch, LNK shortcuts, ShellBags, JumpLists, Event Logs, SRUM) supporting cross-version OS discovery.  
  `Python` • `DFIR` • `Windows Internals` • `Evidence Analysis`

* **[Windows Artifacts Parser](https://github.com/mukulsain09/windows-artifacts-parser)**  
  *Deep-Dive System Artifact Extraction Utility*  
  Targeted forensics tool designed for investigators to parse, structure, and extract evidentiary metadata from registry hives, event channels, and browser caches for forensic triage.  
  `Python` • `Digital Forensics` • `Registry Analysis`
